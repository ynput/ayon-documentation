# TableFilter

Adds a search box and column filters to the Markdown tables inside it. The tables stay ordinary
Markdown tables, so the page HTML always contains every row (crawlers and readers without JavaScript
see them); the component only hides rows in the browser.

```mdx
<TableFilter columns={["Type", "License"]} placeholder="Search the addons">

## Group

| Addon | Type | License |
|---|---|---|
| ... | Server | Free |

</TableFilter>
```

Keep a blank line after the opening tag and before the closing tag, so MDX reads the content as Markdown.

| Prop | Meaning |
|---|---|
| `columns` | Header names that get a filter (a select of the distinct cell values). Without it, every column with 2 to 12 short distinct values gets one. |
| `placeholder` | Text of the search box. |

Tables without a visible row are hidden together with the headings and paragraphs that only introduce them.
Used by `docs/addons/index.md` (generated by `scripts/build_addons_index.py`) and `docs/ayon/plans.md`.
