# YnputCloud addon

<AddonInfo />

The YnputCloud addon provides Ynput Cloud support for an AYON server.It is an addon from Ynput with the flags `licensed`, `power-feature`, `cloud-only` and `cloud-required`, at version 1.1.1. It belongs to the connection between an AYON server and [Ynput Cloud](https://ynput.cloud/), the service that hosts AYON instances and manages accounts and subscriptions.

## About Ynput Cloud

| Topic | Statement |
|---|---|
| Market access | A server must be hosted on AYON Cloud or a local instance must be connected to Ynput Cloud to use the Market. No subscription is needed for this, only an account. |
| Licenses | The license dialog of the AYON server links to the instance in Ynput Cloud, where subscriptions, billing and the license pool are managed. |
| Sign-in | A Ynput Cloud account can serve as a login method. A user can be set to log in only through such options, with password login disabled. |
| Email | Servers with an active Ynput Cloud subscription send email through Ynput servers, without SMTP configuration. |
