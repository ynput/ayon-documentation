# Soko Sync addon

<AddonInfo />

The Soko Sync addon keeps project details up to date between AYON and Soko. It synchronizes projects and their data, such as shots, assets and their attributes, across both platforms. The publisher is Blue Faces, not Ynput, and the current version is 0.1.4.
